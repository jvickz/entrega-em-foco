# Preparação do repositório

## Nome sugerido

`entrega-em-foco`

## Descrição curta

Produto de dados para reduzir atrasos logísticos com diagnóstico, Gate de Prontidão, piloto de 30 dias e dashboard interativo.

## Tópicos sugeridos

`data-science` · `analytics` · `logistics` · `data-product` · `python` · `pandas` · `data-visualization` · `portfolio`

## Publicação no GitHub Pages

1. Envie o conteúdo desta pasta para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch principal, pasta `/ (root)` e salve.
5. Copie a URL publicada e substitua os marcadores em `POST_LINKEDIN.md`.

O arquivo `index.html` já é gerado automaticamente e funciona como página inicial.

## Conferência antes de divulgar

- Confirmar que o dashboard abre na URL do GitHub Pages.
- Testar a primeira tela no celular e no computador.
- Conferir o link do DOI e a atribuição CC BY 4.0.
- Adicionar a URL do projeto na seção **Destaques** do LinkedIn.
- Fixar o repositório no perfil do GitHub.
